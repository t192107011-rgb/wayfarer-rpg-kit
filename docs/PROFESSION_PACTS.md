# 职业性格与越界禁术 · 0.7.1

禁忌能力是玩家可选的残酷手段：职业专长被用来控制、摧残、掠夺或杀死他人。正常性格与台词保留，禁术有独立的越界说明和发动台词。数值代价负责平衡，不能代替禁忌的主题。

| 职业 | 正常倾向 → 越界行为 | 禁术 |
|---|---|---|
| 警员 | 谨慎、重秩序 → 剥夺受审机会，直接处决 | 私刑裁决 |
| 退役军人 | 自律、重同伴 → 不留活口，把死者当武器 | 屠戮军令 |
| 医生 | 细心、有同情心 → 把活人当供体，为自己续命 | 活体取材 |
| 机械师 | 务实、重细节 → 把活人当作可耗尽的机件 | 血肉机匣 |
| 矿工 | 坚韧、重互助 → 封死出口，活埋对手 | 活埋封井 |
| 拳击手 | 直率、好胜 → 放弃竞技尺度，摧毁反抗能力 | 拆骨连打 |
| 商人 | 权衡、重信用 → 强签命债，把人命兑现 | 人命抵押 |
| 记者 | 好奇、执拗 → 从记录死亡变成书写死亡 | 死亡讣告 |

## 选择与表现

默认关闭，Lv.3后营地勾选并确认；取消不提交，换职业清空草稿。不开启时普通职业全部被动/专精照常生效。六个角色独立配置，原三个职业不新增职业禁术。职业禁术无需绑定灵魂，与灵魂技能分别使用按键。

职业面板区分正常行事风格、正常台词、越界说明和禁术台词。战斗用私刑叉印、灭口准星、供体牵线、旋转绞机、黑井、拆骨层数、命债标签、讣告标签辨认效果。当前仍为原创占位画面，没有肢体动画、配音、NPC道德关系或新剧情；“投降/审判”是主题文案，没有新增独立玩法系统。

## 实际机制

所有首次目标必须存活、在范围内且无遮挡。医生、机械师与拳击手仅选最近一名；其他职业标记范围内的敌人。有效攻击指普通攻击、主动技能与攻击天赋；魂技、领域、反射和禁术次生伤害不触发有效攻击加成或传播。标记者被任何伤害击杀都可以触发一次死亡效果。

| 禁术 | 实际效果 | 平衡代价 | 持续 / 冷却 |
|---|---|---|---|

| 拆骨连打 | 130内最近目标初击1.8倍；对标记者的有效攻击从1.8倍起，每次叠加0.25倍、最多3层；第三击起普通目标被打断、硬直1秒，标记者攻击伤害减半；普攻间隔−30% | 12%最大生命，受伤+50%，需持近战武器 | 5 / 24秒 |

- 首领初始硬直最多0.15秒，不能被阈值处决、机匣拘束或强制打断；矿工减慢首领移动与攻击节奏，拳击毁伤仍可降低其攻击伤害。
- 医生按敌人实际损失计算抽取，不根据理论过量伤害制造治疗；仅供体抽取绕过自身的常规治疗封锁，治疗量仍受灵魂、圣杯和护理专精修正。目标死亡、脱离后续范围或被障碍挡住均不能继续抽取。满血也可主动伤害供体。
- 机械师/矿工拘束已经选中的目标，不持续寻找新目标。机械师脉冲/死亡爆发及矿工压伤不触发回能、铜铃或吸血。技能的生命支付与灵魂献祭分别计算，付不起时拒绝技能。
- 士兵连爆逐个清除死亡标记，每具尸体只能引爆一次；商人死亡兑现不再次发放；记者传播与延迟结算不继续传播或累计。
- 拳击手禁术沿用军刀/双匕首，当前没有徒手武器或拆骨动画。层数仅作用在所选目标，结束后攻击力恢复。
- 血量不足以支付并存活、缺目标、冷却、资源不足、闪避或非战斗状态均原子拒绝，不扣资源、不进入冷却。
- 不新增隐形灵魂侵蚀。职业生命支付不经过敌方伤害减免，也不享受灵魂献祭折扣。

## 持久化与边界

运行时保存职业冷却、持续时间、护盾及每名敌人的标记剩余时间、脉冲相位、拆骨层数、讣告延迟伤害。暂停、奖励和后台均冻结；读档只恢复剩余量，不重新抽取、扣费、爆破或兑现。换房保留自身剩余状态与冷却，已清空房间的目标不转移给新敌人。回营清除本轮运行状态，保留选择。

快照v8读取v1—v8。v7旧能力与本次重做不同，迁移时关闭六个职业禁术选择、清空旧职业禁术运行状态，保留实际生命、物品、职业、灵魂、圣遗物和战斗进度。v1—v6照旧默认关闭。不要自动把旧玩家选择解释为同意新能力。

核心实现位于`ActionGame`；`ProfessionPacts`存数据与文案，UI不复制效果计算。标记随敌人保存，来源不符、超出时限、错误层数/债值或死者残留标记均拒绝读取。
