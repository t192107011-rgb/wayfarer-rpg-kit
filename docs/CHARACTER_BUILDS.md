# 角色工坊与天赋星图 · 0.9.0

## 使用

营地上方切换「我的角色」，点选三个独立槽之一，再打开「角色工坊」。编辑名字（1—10字符）、武器、主动技能、出身、特质、衣装颜色、肤色和发型。保存才提交；取消、返回或关闭编辑界面不修改角色。每个槽的经验与天赋独立，改造不重置经验。只能在营地改造。

武器决定普攻；主动技能独立选择。例如卡宾枪配震地可近身解围，军刀配散射可补足远程范围。没有装备栏或完整捏脸网格，外观是程序绘制的像素占位组合。

| 出身 | 优势 | 代价 |
|---|---|---|
| 工业镇 | 最大生命 +18 | 移速 -5% |
| 乡村 | 移速 +7% | 最大生命 -10 |
| 流民 | 基础伤害 +2 | 最大生命 -8 |

| 特质 | 优势 | 代价 |
|---|---|---|
| 守誓 | 药水恢复最大生命的55% | 普攻间隔 ×1.06 |
| 逐猎 | 闪避冷却 -0.12秒 | 受到伤害 +12% |
| 寻火 | 技能冷却 -0.8秒 | 最大生命 -8 |

原来的三个预设角色继续保留，不附加这些出身与特质。六个角色都可培养自己的同款技能树。营地攻击/生命升级仍共享。

## 天赋点与分支

每角色初始2点，累计每80经验增加1点，最多18点。经验在每轮结算获得，角色等级上限仍为20。普通节点可多级学习；第二层需要对应第一层至少1级且角色等级至少2；终阶需要对应第二层2级且角色等级至少4。每个类别的两个终阶互斥，锋刃、逐影、守火可以各选一个，同时拥有三类终阶。营地免费重置当前角色的整个树，返还全部点数，不影响经验和其他角色。

| 分支 | 第一层（3级） | 第二层（2级） | 终阶二选一 |
|---|---|---|---|
| 锋刃 | 淬锋：每级伤害+2 | 三拍：第三次普攻倍率每级+12% | 裂地回响：第三次普攻附带范围震波；孤焰：低血增伤，但始终承受更多伤害 |
| 逐影 | 轻步：每级移速+3%、闪避冷却-0.07秒 | 借势：闪避后3秒内下一次普攻每级增伤15% | 残影破：闪避起点伤害与眩晕；回环：有效闪避减少技能剩余冷却2.5秒 |
| 守火 | 灯芯：每级生命+8 | 余温：每级技能冷却-0.4秒，施放获得6点护盾 | 长明：技能恢复8%生命；镜火：额外护盾与受击反震 |

护盾不会反复叠加超出当前天赋允许的上限；进入下一房间会清零。借势只有成功闪避才激活，被下一次普攻一次性消耗。震波、闪避脉冲与护盾反震是范围效果，和原有震地一样可穿过小障碍；普通近战和箭矢仍受障碍阻挡。卡宾枪现在也应用第三次连击的基础1.35倍伤害与三拍增幅。

示例：

- **反击灯卫**：军刀＋环刃＋工业镇＋守誓，守火支路到镜火；用护盾和近身反震维持战线。
- **回环游猎**：卡宾枪＋震地＋乡村＋逐猎，逐影支路到回环；闪避周转技能，震地解围。
- **孤焰旅人**：双匕首＋散射＋流民＋寻火，锋刃支路到孤焰；以更高风险换取低血爆发。

## 存档与扩展

`ActionSave` 当前写入v10，读取v1—v10。v1迁移保持全部原有动作存档字段，增加三个默认自定义档案与六套空天赋，按已有经验推导可用点数；随后保存为v10。目录与应用ID不变。自动存档及三个手动槽采用同一协议。v10不能交给只支持旧协议的APK读取。

角色槽编号、天赋节点编号和枚举值是稳定存档ID，不可随意重排。新增节点需升级协议并明确迁移。`BuildSystem` 保存定义、预算、前置与互斥检查；`ActionGame` 唯一负责实际效果；`ActionSave` 校验每个角色、树预算、等级、前置、互斥与当前战斗状态。编辑器使用副本，确认时核心校验并提交。

`custom=-1` 表示预设角色，0—2表示自定义槽；`hero` 始终是当前武器编号。`buildId()` 将预设角色映射到0—2，自定义映射到3—5。更换自定义武器不会把经验转给预设角色。读取半次挥砍会取消未完成动作，并保留已消耗借势状态，避免读档重复获益。

0.9.0扩大终阶覆盖并新增跨类别组合，完整数值、8种组合和新示例见[无尽与流派规则](ENDLESS.md)。长明的命中回血、镜火补盾和回环追击强化均实际参与战斗；未命中不触发命中收益。
