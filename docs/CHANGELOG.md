# 更新记录

## 0.8.0 · 黑钟回响

- **更有压力的敌群**：射手双轮扇射，新增预判追猎者、封路焚灯者和护盾敲钟人。五区配置逐步混编，监工改为冲击环/双轮弹幕/三段落点三套招式，半血后提速。
- **技能二段衔接**：主动技后2秒内再次按技能，分别追加断层追击、破盾点射、穿影突刺。光辉命中补盾并净化；禁忌可引爆既有诅咒。
- **侵蚀能够累积到100**：使用禁忌后8秒才开始每秒消退1点。50/75侵蚀增加输出，100触发6秒失控，输出+40%并周期流失生命；回落到70以下且失控结束后才能再次触发。
- **五章主线与三种结局**：沿失踪列车追查旧厂、假死亡记录和黑钟。清场打开现场线索；两种决定永久记录、一次性发奖，也可回营补读。
- **独立人物线**：六个角色各自记录三章经历，依首次解锁时的职业使用12套文本（含无职业）。选择留下生命或攻击被动；换职业不改写过去，不会自动开启职业禁术。
- **快照v9**：读取v1—v9；v8职业禁术选择保留。新增状态保存追击窗口、失控脉冲、危险区预警、敌方护盾/预判落点和剧情决定。

[战斗、侵蚀与剧情规则](BLACK_BELL.md)。本版剧情通过文字对话与选择呈现，尚无可行走NPC、配音或过场动画。
