# 四种职业 · 0.9.2

当前职业系统已整体重做，只存在四个职业，ID连续且从0开始。所有六个角色档案分别保存职业、专精和背景。旧版本职业编号不再兼容；读取v1—v10存档时，职业统一重置为猎人，专精重置为无专精，背景经历保留。角色武器、出身、特质、经验、天赋、灵魂、圣遗物、剧情和战斗进度继续保留。

## 职业与主动技能

| 职业 | 主动技能 | 实际效果 |
|---|---|---|
| 猎人 | 瞬时猎杀 | 发动时造成大范围伤害；持续10秒，攻速与移速大幅提高并获得吸血。期间每秒损失1%最大生命，生命到达30%时停止损失。 |
| 刺客 | 刀尖之舞 | 持续10秒。攻击额外扇形发射3把小刀；击杀立即重置职业技能冷却并恢复3%最大生命，攻速小幅降低。 |
| 侦探 | 灯中之影 | 持续10秒。生成全场吸引场，持续吸引敌人并造成低额伤害；职业技能冷却速度提高，自身受到的攻击伤害提高15%。 |
| 记者 | 静默之声 | 持续10秒，大幅提高自身攻速与职业技能冷却速度；治疗效果降低80%。 |

职业主动技能由战斗中的「技能」按键触发；魂技由独立的「魂技」按键触发。职业技能不依赖灵魂绑定。四种职业的主动技能不能互换，也不会因武器类型变化。

### 具体触发规则

- 猎人：发动瞬间对半径430范围内敌人造成一次高额伤害。持续期间攻速间隔缩短、移速提高45%，有效攻击造成伤害的20%转化为治疗；每秒支付最大生命值1%，生命到达30%时停止支付。自我支付不计入敌方造成的房间伤害。
- 刺客：持续期间每次普攻额外向面朝方向扇形发射3把小刀，每把造成普攻伤害的35%。有效击杀恢复最大生命值3%，并将职业技能冷却立即归零；技能持续时间不因击杀自动延长。攻击间隔增加12%。
- 侦探：吸引场覆盖全场敌人，持续向角色方向牵引并造成低额持续伤害。职业技能冷却计时速度翻倍；受到敌人攻击时承伤提高15%。
- 记者：攻速间隔缩短，职业技能冷却计时速度翻倍；所有治疗来源最终恢复量降低80%。不改变攻击伤害，也不附加伤害传导。
- 四种职业技能持续时间均为10秒，基础冷却为24秒。冷却从发动时开始计时；侦探与记者在技能持续期间额外加速冷却。
- 进入新场景时，职业技能、魂技和闪避的冷却全部重置；本轮奖励成长和职业技能冷却速度成长保留。
- 三项区域奖励达到原上限后依次替换：伤害增益满级后改为职业技能冷却速度+10%（最多叠加8次）；生命上限奖励持续增加，最高99999；移速增益满级后改为本轮票券+15。
- 双匕首突刺不再附带无敌；双匕首基础攻击间隔由0.10秒调整为0.12秒。普通闪避的无敌窗口不受影响。

## 专精

角色达到Lv.3（160经验）后开放专精。猎人与记者各有两个专精；刺客和侦探目前没有专精。

| 职业 | 专精 | 效果 |
|---|---|---|
| 猎人 | 狙猎 | 距离目标超过200时，有效攻击伤害提高18%。 |
| 猎人 | 游击 | 闪避后3秒内，下一次有效攻击伤害提高25%。 |
| 记者 | 战地采访 | 对首领的有效攻击伤害提高15%。 |
| 记者 | 调查报道 | 本轮结算角色经验提高20%，向下取整。 |

专精只影响对应职业。切换职业时专精归零；切换角色不会共享专精。职业技能、专精与背景可以自由组合，不限制武器、出身、特质、灵魂或圣遗物。

## 背景经历

背景与职业独立，可自由组合；六个背景的实际效果保留：

| 背景 | 效果 |
|---|---|
| 无额外经历 | 不附加背景被动。 |
| 铁厂学徒 | 每次进入新区域获得10点职能护盾。 |
| 乡间向导 | 移速额外提高3%；补给所基础恢复由18%提高到26%最大生命。 |
| 铁路信使 | 生命低于35%时，移动速度额外提高12%。 |
| 乡村医护 | 每瓶药水基础恢复额外增加6生命。 |
| 墓园看守 | 击败敌人基础恢复1生命；已缔结灵魂时获得魂能，普通敌人2点、首领8点。 |
| 码头拾荒者 | 每名敌人的票券掉落额外增加2。 |

背景、出身与性格特质分别生效。更换职业不会删除背景。

## 已移除内容

旧职业：护路卫士、边地猎人（旧ID）、秘仪学者、警员、退役军人、医生、机械师、矿工、拳击手、商人，以及旧职业禁术系统，均已从当前职业系统删除。旧专精与旧职业被动不再生效。时针没有加入本次职业列表。

## 存档与实现

- 当前快照协议为v12。
