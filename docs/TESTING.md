# 动作版测试与验收

## 核心回归

`bash scripts/test-core.sh` 使用 JDK 17，无第三方依赖。保留旧核心的 91 项回归，新增 `ActionTests`：

- 轴向/斜向速度一致、墙/障碍碰撞、暂停、非有限输入拒绝。
- 一次挥击不能逐帧重复命中；按住攻击能连续出招；远程弹丸实际命中。
- 角色技能差分、技能/闪避冷却、闪避无敌结束后的正常受伤、受击保护。
- 满血不扣药水、普通药水正确恢复。
- 80 个种子 × 5 个关卡，共 400 种房间布局：出生点/敌人位置合法、中央路线和出口通畅。
- 清场选择增益、奖励防重复、两出口效果、失败/胜利结算、共享永久升级及本轮增益清零。
- 完整快照恢复、随机状态连续、无效版本/位置/数值/数量拒绝、近战恢复不能重复伤害。
- 三角色累计 54,000 步连续模拟，过程中定期保存与恢复。

检查数量含生成布局中的多次断言，不能理解成同等数量的独立功能测试。最新结论以脚本输出和对应 commit 的 Actions 记录为准。

## Android 实际运行 smoke

`SmokeInstrumentation` 使用系统 Instrumentation，不依赖外部测试服务。CI 在 API29 x86_64 模拟器安装主 APK 与测试 APK，并运行 `scripts/emulator-smoke.sh`。

覆盖启动、横屏、角色选择、开始远征、双指同时移动和攻击、闪避、技能、暂停冻结、AtomicFile 手动存档读取与继续。`action-ui-smoke` 产物保存日志、崩溃日志和截图。

`01-camp.png` / `02-dungeon.png` / `03-pause.png` 是交互过程截图；`04-combat-render.png` 是测试配置的固定战斗场景渲染，方便核对预警、敌我形象和控件，不代表自然游玩到达的战况。

## 真机仍需验证

- 低端设备连续运行时帧率、发热与耗电。
- 不同刘海、横屏比例、手指大小下的触控手感。
- 系统强杀、存储空间不足、返回桌面、电话打断的恢复。
- 耳机/蓝牙延迟、音效音量、系统静音行为。
- 正式关卡难度、首领平衡和持续游玩体验。

当前自绘界面没有完整的逐控件 TalkBack 导航，也尚未提供手柄或键盘操作。这些功能不应被宣称为已支持。

## 0.3.0 新增验证范围

- `BuildTests` 检查81种战斗组合、外观与名称存储、草稿隔离、独立经验、点数预算、前置、互斥、免费返还、战斗内禁止改造和全部6种终阶效果。
- 用v1字段集验证迁移、原远征与经验保留；拒绝超支、缺前置、多终阶、非法外观及无依据的护盾/借势快照。
- 六种满天赋自定义构筑合计18,000个模拟步，周期性快照恢复；另保留原54,000步动作测试和400个布局测试。
- 模拟器从营地点开工坊，修改名字、武器、跨职业技能与外观，保存/取消；点击技能树学习基础节点，验证终阶锁定，保存恢复配置，再实际施放跨职业技能。原多指移动/攻击测试继续保留。
- 新截图05为实际原生编辑器，06为实际技能树，07为实际自定义角色营地，08为实际自定义角色战斗画面；04仍是固定测试场景，不代表自然通关。
- 不把这些自动化检查当作真机触控手感或完整平衡测试；覆盖状态以对应CI运行结果为准。
