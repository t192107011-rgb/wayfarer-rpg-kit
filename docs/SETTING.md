# 灰桥封锁线 · 1887

《灯下归途》改为以19世纪社会生活为基础的原创魔幻故事。地点是虚构欧洲工业城镇灰桥，年代为1887；并非真实历史事件复原。铁路、煤矿、纺织厂、煤气照明、货运票券和乡村医护构成日常，少数人能接触灵魂与圣遗物。

夜班列车失踪，封锁线内出现模仿死者声音的异象。被滞留的护路人、猎人和夜班工人沿铁路前往矿井，收集遗物并打通归路。

| 阶段 | 场景 | 环境线索 |
|---|---|---|
| 1 | 货运站场 | 无人领取的行李，失踪值班员 |
| 2 | 林缘轨道 | 枕木记号，引向旧厂的声音 |
| 3 | 旧纺织厂 | 停工后仍在运动的机器，墙内遗物 |
| 4 | 墓园礼拜堂 | 矿难名单与异常钟声 |
| 5 | 深井泵房 | 裂隙污染，失魂监工 |

营地标题下可点击「事件档案」；操作说明也可进入。开场、清场奖励与暂停界面显示地点线索。现在是五个顺序推进的战斗区域，线索以文字呈现；尚未实现NPC对话、证物交互或分支调查任务。

## 现实底色与魔幻边界

角色穿长外套、便帽与靴子，携军刀、卡宾枪或双匕首。职业包括警员、退役军人、医生、机械师、矿工、拳击手、商人、记者，并保留护路卫士、边地猎人、秘仪学者；背景来自早年的谋生经历。秘仪学者属于隐秘结社，施法不是社会常识。光辉回应保护与救助，禁忌来自矿井裂隙并付出生命/侵蚀代价；圣遗物寄居于普通旧物中。

画面加入轨道、枕木、砖厂烟囱、煤气灯、木箱、纺织设备、墓碑和泵房金属构件，保留战斗预警可读性。均为Canvas绘制的原创占位资产，装饰与碰撞严格分离。主资源显示为票券，升级/掉落数值和原存档整数保持。

当前枪械是简化动作投射物，没有弹仓、换弹、弹药购买或真实弹道。散射和灵魂变体保留既有技能机制。体积夸大的首领和超自然范围技能属于魔幻表现，不能当成历史考据模拟器。
