# 灵魂机制 · 更新至0.8.0

> 本页记录原系统版本。0.9.0的扩大范围、回环3秒追击、每类终阶与新保存边界以[无尽与流派规则](ENDLESS.md)为准。

营地下方「灵魂祭坛」可为当前角色缔结光辉或禁忌灵魂，并从该灵魂的两招专属技能中选一招。三个预设角色与三个自定义角色各自保存配置。自定义角色也可在工坊编辑灵魂与专属技能，预览其主动技能变化。所有更换仅限营地，确认才提交；可自由回到「未缔结」。角色经验、天赋和外观保留。

## 魂能与操作

- 每轮远征初始40魂能，上限100；每次实际命中获得 `min(4, 实际伤害×0.08)` 魂能，打在已经死亡的敌人上不会充能。
- 新增右侧「魂技」按键，施放当前专属技能，消耗40魂能，并使用独立冷却。低于40点时按钮显示「蓄能」。技能冷却时显示秒数。
- 光辉护盾吸收敌方伤害也可充能，每次最多6点。专属技能和领域造成的伤害不回充；专属技能授予的护盾仍可从敌方攻击充能。
- 魂能、专属冷却和侵蚀跨房间保留；领域、辉盾和血契状态进新房间时结束。回营与新一轮远征重置临时状态。
- 暂停、后台和选奖励期间，领域、侵蚀、血契与冷却都停止。每种状态均保存到战斗快照。

## 光辉灵魂

所有治疗量+15%；主动技能冷却+0.5秒，并获得8点辉盾。辉盾独立于天赋护盾，先吸收伤害，重复授予取较高值，不累加。最高实际授予30点。

|---|---|
| 震地 | **圣钟震地**：范围195（原160）、1.65倍伤害（原1.8），眩晕0.9秒，净化范围内敌方弹丸。 |
| 箭雨 | **折光箭雨**：五发改三发，每发1.5倍伤害，最多命中三个不同敌人。穿透敌人但不穿墙，读档也不会重复命中同一目标。 |
| 环刃 | **守誓环刃**：范围140（原125）、1.8倍伤害（原2.2），无敌0.85秒，额外6辉盾并净化范围内弹丸。 |

天赋共鸣：灯芯每级额外+2最大生命；余温每级额外+4辉盾。技能树的共鸣节点带星标，详情同时列出基础效果与灵魂追加效果。

|---|---|---|

## 禁忌灵魂

主动技能冷却-0.6秒，施放时消耗4%最大生命并增加18侵蚀。专属技能消耗8%最大生命并增加30侵蚀。献祭绕过护盾，不触发受击回能、反震或无敌；献祭本身不会致死，也不能把低于1的生命反向补到1。

侵蚀0—100：每点使受到伤害+0.4%、治疗量-0.3%，100点时分别为+40%和-30%。停止使用禁忌技能8秒后，每秒消退1点，血契或领域仍在时暂停消退；普攻不会延迟消退。50/75侵蚀时输出分别+15%/+25%；100触发6秒失控，期间输出+40%，每1.5秒失去3%最大生命（保留不致死下限）。失控结束且侵蚀降至70以下才能再次触发；保持100不会循环触发。追击消耗2%生命并增加12侵蚀。界面显示当前侵蚀与实际百分比代价。

诅咒持续3秒，使目标受到的伤害+15%；重复施加刷新时间，不叠加倍率。敌人脚下紫环和「咒」字表示诅咒。

| 原主动技能 | 禁忌变化 |
|---|---|
| 震地 | **深渊牵引**：范围220、1.5倍伤害，将敌人向自己拉近并施加诅咒；首领只承受20%牵引距离，碰撞仍生效。 |
| 箭雨 | **咒棘箭雨**：七发扇形箭，每发1.05倍伤害，命中施加诅咒。 |
| 环刃 | **噬影环刃**：范围150、2.6倍伤害并施加诅咒；无敌缩短为0.35秒。 |

天赋共鸣：三拍每级额外+6%第三击倍率；借势每级额外+5%伤害。血契、诅咒、连击和借势按各自规则组合，侵蚀持续约束恢复和承伤。

| 专属技能 | 效果 | 独立冷却 |
|---|---|---|
| **裂隙之井** | 在前方生成185半径、持续4秒的裂隙，每0.5秒牵引、施加诅咒并造成0.5倍伤害。 | 16秒 |
| **血契狂宴** | 周围160范围爆发1.2倍伤害并诅咒；进入6秒血契，伤害+25%、普攻间隔-20%，有效攻击吸取实际伤害的8%生命。每次基础吸血不超过最大生命的1.5%，再受侵蚀减疗影响；专属技能与领域伤害不吸血。 | 18秒 |

范围震地、环刃和领域延续原模板的穿过小障碍效果；普通近战、箭矢、光矛和牵引移动仍遵守各自碰撞规则。

## 存档与扩展

当前保存协议为v9，兼容读取v1—v8；旧角色默认「未缔结」，保持原有玩法，不自动附加灵魂、代价或魂能。新存档记录六个角色的灵魂配置、魂能、辉盾、专属冷却、侵蚀消退延迟、血契剩余时间、诅咒、领域剩余时间/下一次脉冲，以及穿透箭已命中ID、追击窗口、失控持续时间/下一次脉冲与阈值锁。动作应用ID与存档目录不变，三个手动槽不清空。

`SoulSystem` 提供稳定ID、名称、技能说明、冷却与天赋共鸣文案；`ActionGame` 执行规则，`SoulAltar`/`CharacterWorkshop` 只编辑草稿与确认提交。新增灵魂或改变序列化字段时应增加明确迁移，不能重排已有ID。当前没有灵魂随机掉落、魂魄装备栏或灵魂等级；缔结功能在营地直接开放。

APK仍使用CI临时debug签名；存档格式兼容不代表不同签名APK能覆盖安装。已有安装存档时不要通过直接卸载来绕过签名限制。长期发布应配置固定私有签名，密钥不可提交源码。
