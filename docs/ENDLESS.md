# 0.9.0 · 无尽远征、敌势与流派

营地保留「剧情远征」，新增「无尽远征」。剧情模式仍在第五区域胜利结算；无尽模式每五层循环五种区域与监工，首领清场后继续选奖励、走出口。共享记录的是**已清除的最深层**，死亡或主动结束不会抹去。

## 无尽循环与结算

- 第6/11/16/21/26层起，在原区域敌群上分别追加1/2/3/4/5名随机特殊敌人；追猎者、焚灯者、敲钟人可混编。之后追加数量保持5，避免实体无限堆积。
- 每五层首领额外提供35本轮票券。死亡或暂停后主动结束带回已拾取票券的70%，按击杀结算经验；不能重复结算。普通剧情胜利仍为全部票券加40。
- 清场增益上限：伤害+40、生命+200、速度+48%（6级）。伤害满后同项奖励改为12票券；生命满后仍基础恢复35；速度满后仍重置技能冷却。新远征清空本轮增益。
- 主线和人物线仍由区域清场解锁，已选决定不能重复领取。遗物发现沿用每轮第2/4/5区域各一次的标记，不会每五层刷出新收藏。
- 层数保存上限999999；到上限后仍可重复当前层。无尽指没有第五层通关终点，并不代表敌人、数值或存档无边界。

## 动态敌势

`ThreatSystem.enter()` 在**进入区域**时计算敌势、生命下限、伤害下限。它不会在玩家扣血、喝药、发动爆发后给当前敌人突然加血。HUD显示当区敌势倍率。

```
成长 = (等级-1)×0.035 + 营地攻击级×0.04 + 营地生命级×0.025
     + 已花天赋点×0.018 + 已装备遗物数×0.07
     + 有专精时0.08 + 有灵魂时0.10 + 人物被动数×0.03
深度 = 无尽时 min(2.5, (层数-1)×0.065)，剧情为0
敌势 = min(6, 1.2 + 区域号×0.12 + 成长 + 压力 + 深度)
敌人生命 = max(原敌人生命×敌势, 角色最大生命×1.2 + 基础攻击×2)
单次敌方伤害 = max(招式原伤害×敌势, 角色基础攻击×1.12)
```

这里的基础攻击包含永久成长和本轮伤害增益，排除孤焰、灵魂爆发等短时倍率。敌人生命与未减免单击领先角色的对应基础值；并非承诺每种敌人都胜过角色整套技能爆发。护盾、职业减伤、拳击手拆骨等效果仍正常参与伤害结算。

本轮压力在0至0.6之间：当区45秒内清场且实际失血不超过最大生命12%，加0.12；实际失血达到55%，减0.12；其余保持。只在清场事件计一次，下一区生效；回营或新远征重置。统计累计实际敌方失血，不因治疗抵消，不含自身献祭和侵蚀。暂停、奖励和命中停顿期间不推进计时。

敌方接敌/攻击范围随敌势最多增加20%；移动、冲刺和弹速在现有敌势上限内最多增加27.5%。仍保留蓄力、锁定朝向、危险区延迟和受击保护，不移除预警。

## 攻击覆盖与终阶流派

军刀普攻距离120，双匕首100；主动震地范围200、光辉235、禁忌260；环刃160/180/190。追击为裂线320、点射640、突刺最多180。孤焰低血时近战与范围技能/追击覆盖再乘1.25；步进碰撞和各技能原有视线规则保留。敌人近战打击基础范围110，焚灯与首领危险区也扩大；表现使用核心范围函数。

三类终阶**各自二选一**，可同时拥有锋刃、逐影、守火各一个，共8种完整终阶组合。初始2点，每80经验加1点，最多18点（1280经验）。12个稳定节点ID不变；最低12点可各走一条终阶，剩余点数补满基础节点。营地可免费重置，各角色独立。

| 终阶 | 单独增强 | 跨类别组合 |
|---|---|---|
| 裂地回响 | 第三次普攻185范围、75%伤害震波 | 与镜火：震波实际扣血后补4护盾 |
| 孤焰 | 低于40%生命时伤害+55%、覆盖+25%；始终多受15%伤害 | 与长明：低血追击命中恢复6%，替代3% |
| 残影破 | 有效闪避起点120范围、105%伤害，短眩晕 | 与镜火：每次有效闪避补6护盾 |
| 回环 | 有效闪避减技能冷却2.5秒；追击窗口3秒、追击伤害+20% | 与长明：追击实际扣血后再减0.8秒冷却 |
| 长明 | 初段技能恢复8%，追击实际扣血恢复3% | 追击落空、被护盾完全吸收不触发命中恢复 |
| 镜火 | 技能额外12护盾，受盾伤向150范围反震吸收量65%；追击实际扣血补6护盾 | 所有补盾受余温等级×6+12上限约束 |

可尝试：裂地+残影+镜火（连击与闪避补盾）、孤焰+回环+长明（低血爆发与命中续航）、裂地+回环+长明（稳定连击与技能周转）。职业、灵魂、双遗物继续独立搭配。禁术仍由玩家主动选择，未默认开启。

## 概率药瓶

| 击杀来源目标 | 独立药瓶掉率 |
|---|---|
| 普通近战、射手、冲锋者 | 12% |
| 追猎者、焚灯者、敲钟人 | 18% |
| 监工首领 | 50% |

每名敌人在死亡处理时仅掷一次药瓶概率，使用已保存的随机状态；读档不会重掷同一次击杀。与原来的1/6即时治疗掉落、票券分别结算。掉落不要求特定武器或灵魂。

新远征初始2瓶，最多携带5瓶。绿色药瓶靠近拾取，清场自动收集；满包药瓶留在当前地面，喝药腾出位置后可拾取。选择奖励后仍可在本区喝药、捡剩余瓶子；走出口会清除未拾取的本区掉落。满血且无圣杯净化需求时不能空耗药水。职业医生禁术治疗封锁仍有效。

## 保存、测试与扩展

v10保存无尽开关、当前/最深层、当区敌势、压力、进入时属性下限、累计失血/计时和每个掉落的药瓶类型。读取v1—v10；旧版终阶按原来的全局互斥与16点预算校验，迁移不退款、不改写已选项；升级后可在营地学习其余类别终阶。

旧档正在战斗的敌人保持原生命和中性敌势，避免迁移突然变强；下次进入区域开始采用新公式。v10继续验证三手动槽的独立内容；无尽第五区REWARD合法，剧情第五区REWARD仍非法。降级到旧APK不能读取v10。

`EndlessTests`覆盖8种终阶组合、实际命中协同、90层连续流程、剧情终点、24种高层灵魂/终阶组合快照、累计7500次死亡掉落、满包/喝药/拾取和非法快照。Android测试用受控清场夹具验证第五首领到第六层，并实际点击天赋与药水控件；这些不是自然玩家通关证据。

修改公式先改`ThreatSystem`和核心行为，再改说明。新敌人类型必须显式决定掉率；变更奖励上限同时修改`ActionSave`边界和满级文案。不得通过渲染函数或加载存档重新随机化敌势/药瓶。
