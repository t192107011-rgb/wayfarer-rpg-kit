# 圣遗物 · 0.5.0

营地右上方打开「圣遗物」。收藏全角色共享，三个预设角色与三个自定义角色各自保存两个装备槽。同件可以由不同角色携带，但同一角色不能重复装备。只在营地确认后提交，取消保留原配置；「清空两槽」只清草稿，仍需确认。界面同时显示未发现条目及完整效果。

## 获取与携行

- 初始拥有余烬灯芯、旅人罗盘，初始装备槽为空。不会自动改变旧档战斗数值。
- 清空第2、第4庭院以及第5庭院首领，各随机发现一件尚未拥有的圣遗物。不重复抽取已拥有条目；两次完整远征可以收齐其余六件。
- 发现当场永久收录，失败或主动结束仍保留；本轮装备不变，回营后可更换。
- 集齐后，上述节点改为本轮余烬+15，结算仍遵循胜利全额、失败70%的原规则。
- 随机选择使用存档中的随机状态；每个节点每轮仅发放一次，奖励画面读档不会重新抽取。
- 收藏的“永久”指当前档案内跨远征保留。读取较早的手动存档会恢复当时收藏，不与其他快照合并；新建档案重置收藏，三个手动槽保留。

## 八件圣遗物

| ID | 圣遗物 | 效果 |
|---|---|---|
| 1 | 余烬灯芯 | 最大生命+12，与营地、等级、天赋叠加。 |
| 2 | 旅人罗盘 | 闪避冷却-0.15秒，与步法及轻装叠加。 |
| 3 | 回响铜铃 | 闪避后3秒内下一次有效攻击伤害+35%，命中消耗；普攻、主动技能和攻击天赋可触发，魂技、领域、反震不触发。 |
| 4 | 慈悲圣杯 | 治疗量×1.1；光辉喝药额外获得12辉盾，取较高值不叠加；禁忌喝药先净化20侵蚀，再按净化后的减疗恢复。满血但有侵蚀时可以喝药。 |
| 5 | 日冕碎片 | 缔结任一灵魂时初始魂能40→55；光辉为70；未缔结不生效，进房不重复补能。 |
| 6 | 渎誓指环 | 诅咒目标所受伤害再×1.1；禁忌生命献祭×0.75，普通技能消耗4%→3%，魂技8%→6%。侵蚀代价保持原值。 |
| 7 | 荆棘圣印 | 将敌方攻击造成的实际生命损失的25%反震给周围120范围敌人；完全格挡不触发。反震不回魂能、不吸血、不触发铜铃。 |
| 8 | 逆命沙漏 | 每轮一次，敌方致命伤害时保留25%最大生命并获得1秒无敌。不是治疗，不受治疗加成/减益；跨房、暂停和读档均不补次数。 |

铜铃只增强一次实际命中，扇形或穿透弹丸不会让全部目标都吃到该加成；多个目标同帧命中时依次处理。3秒倒计时随战斗推进，暂停、选奖励和后台冻结；进房清空未用的铜铃效果。禁忌献祭本身不致死，不触发沙漏或荆棘。荆棘按实际扣掉的生命计算，过量伤害不放大反震；反震不穿出120范围。原有天赋反震保留原规则，但不消耗铜铃。

光辉与圣杯的治疗修正相乘：1.15×1.1=1.265。禁忌为(1−侵蚀×0.003)×1.1。战斗HUD显示实际净治疗百分比。圣遗物没有随机词缀、强化等级或额外主动按键。

## 存档与扩展

快照协议v4读取v1—v4。旧版迁移只加入两件起始收藏与空装备槽，原角色、灵魂、领域、经验、天赋和远征保留；已经打开的旧奖励画面不追补新掉落。保存六套双槽配置、收藏位图、当轮发放标记、发现提示、铜铃剩余时间、沙漏使用状态。非法ID、重复装备、未拥有装备、非法位图/跨房发放进度及无来源的临时状态会拒绝读取。

`RelicSystem` 持有稳定ID、文案和装备校验；`ActionGame` 处理获取与效果；`RelicCabinet` 只编辑草稿。新增遗物需要扩展固定ID、收藏掩码、存档边界与迁移，并覆盖实际触发及组合测试。不要重排现有ID。

测试APK继续使用CI临时debug签名。存档格式兼容不意味着不同签名可以覆盖安装；有旧存档时应保留旧安装，不通过卸载绕过签名限制。
