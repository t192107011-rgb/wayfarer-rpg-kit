# 验收与验证

## 可复现自动测试

运行 `bash scripts/test-core.sh`。不需要 Android SDK 或第三方测试库，只需要含编译器模块的 JDK 17。

测试从正常新游戏开始，实际调用移动、交互、战斗和购买接口贯通两段主线；还检查：

- 战斗开始、胜利、奖励与升级；战斗过程每步保存/恢复后状态相同。
- 法力不足、物品不足、满生命时不会错误扣除回合或资源。
- 防御减伤、法力恢复、首领禁止逃跑、普通敌人逃跑、战败扣金币回村。
- 商店位置、资金、装备重复购买和物品上限。
- 碰撞、地图/事件引用合法、宝箱与任务奖励不能重复领取。
- 休息恢复、普通敌人刷新、首领不刷新。
- 存档大小、格式、版本、字段范围、引用与任务一致性检查。

本地首次测试结果：**91 项检查全部通过**。这是纯逻辑测试，不代表已在 Android 真机运行。

## Android 构建门禁

GitHub Actions 使用 Java 17、Gradle 8.9、AGP 8.7.3、Android SDK 35，先运行上述逻辑测试，再执行 `lintDebug assembleDebug`。构建状态与错误以 Actions 的实际运行日志为准；成功后会上传 APK 与 lint 报告。

## 发布前真机验收清单

以下项目需要在模拟器或真机实际运行后逐项确认，不应仅因编译成功而视为通过：

1. 冷启动、首次启动；按钮可点击、中文字显示正常。
2. 360dp 小屏和横屏能滚动操作；系统状态栏/导航栏不遮挡按钮。
3. 村庄长老接任务、林地三场战斗、回村领奖、遗迹首领、回村结局。
4. 背包使用、购买装备、旅店休息、打开宝箱。
5. 战斗中切后台/重启，敌我 HP、MP、回合数不丢失。
6. 三个手动槽保存/读取，取消覆盖，新游戏保留手动槽。
7. 自动存档损坏提示；有效手动存档可恢复；取消读取不改变当前状态。
8. 旋转屏幕、低内存进程回收后的自动恢复；模拟磁盘写入失败时明确告警。
9. TalkBack 对方向按钮和状态文本可读，大字号不导致关键功能不可到达。

当前没有仪器化 UI 自动测试或真机验证记录。正式版本需要补充这些验收结果。
