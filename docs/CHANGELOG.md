# 0.4.0-souls

## 0.5.0 · 圣遗物

- 新增8件圣遗物、共享收藏及六角色独立双槽携行，营地确认/取消/清空草稿。
- 第2、4、5庭院清场发现未拥有遗物；发现即保留，集齐后补偿本轮余烬。
- 接入生命、闪避、铜铃命中、圣杯治疗/净化、日冕魂能、禁忌献祭与诅咒、荆棘反震、沙漏保命。
- 战斗HUD显示携行、铜铃和沙漏状态，治疗提示计入圣杯；奖励与结算显示发现。
- 保存协议v4，显式兼容旧档，保留临时效果与当轮发放/消耗记录，防止读档重抽或补沙漏次数。
- 新增圣遗物核心与Android交互测试；13为实际图鉴界面，14为第二庭院清场测试场景的奖励界面。


- 新增光辉、禁忌两种独立灵魂配置，预设/自定义六角色均可缔结或解除。
- 三种基础技能各增加光辉/禁忌变体，共六种变化；新增四招独立魂技与魂能规则。
- 新增辉盾、领域净化、穿透命中记录、牵引与首领抗性、诅咒、献祭、侵蚀和血契吸血。
- 四个天赋节点获得灵魂共鸣；界面明确展示收益与代价。
- 新增原生灵魂祭坛，工坊灵魂编辑、独立魂技按键、魂能和侵蚀HUD、领域/诅咒画面与差异音效。
- 存档v3兼容v1/v2，保存全部魂技计时、领域脉冲和穿透命中记录，避免读档重复伤害或资源返还。
- 新增纯Java灵魂行为测试、满天赋组合压力测试和模拟器灵魂交互验证。

# 0.3.0-forge

- 新增3个独立自定义角色槽与原生角色工坊，支持姓名、外观、出身、特质、武器与独立主动技能。
- 六个角色各有独立技能树与经验；12节点、6个互斥终阶、前置与等级限制、免费重置。
- 战斗加入闪避蓄势、连击震波、低血增伤、闪避脉冲、回避回能、护盾、技能治疗与护盾反震。
- 长弓第三次普攻现在应用连击倍率。
- 存档升级v2并兼容迁移v1；编辑草稿取消不写入，保持原有手动槽。
- 增加81组合与6种满天赋流派验证、旧档迁移与无效构筑拒绝测试；扩展模拟器角色编辑、技能树和存读档测试。

# Changelog

## 0.2.0-action · 2026-10-23 · demo

根据用户明确的参考《莫塔守山人》，将应用入口重做为横屏俯视角即时动作 RPG。

新增三种角色、连续移动/攻击、短暂无敌闪避、主动技能、多类带预警敌人、首领、五段庭院、清场奖励、局外共享升级、角色经验、原创短音效、战斗快照和多指操作验证。

使用独立包名 `io.wayfarer.rpg.action`，不覆盖旧应用。旧存档与动作版不互转；旧核心和回归测试保留。main 不变，动作版位于 demo。

## 0.1.0 · 2026-10-19 · main

早期回合制原型，不符合后来明确的动作 RPG 方向，保留作历史版本。
