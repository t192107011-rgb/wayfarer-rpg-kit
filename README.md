# 灯下归途 · Wayfarer Action RPG Kit

**0.6.1-professions · demo 分支 · Android 原生 Java · 横屏 · 离线**

俯视角即时动作 RPG 模板。以《莫塔守山人》一类游戏的移动战斗、角色差异、地牢冒险与持续成长为方向，使用原创占位角色、地图和音效，方便继续开发自己的作品。

## 0.6.1 · 八种日常职业

在原有职业上新增**警员、退役军人、医生、机械师、矿工、拳击手、商人、记者**，各带两个专精，共11种职业、22种专精。普通职业的能力来自训练、药品、防护、采购与调查经验，无需灵魂即可生效。

医生提升药水并可学习急救；机械师缩短技能冷却或制作护具；矿工可选采掘/支护；拳击手加强近战节奏；商人提高敌人掉落、议价采购；记者可选首领战或经验成长。警员与军人的专精分别偏巡逻/侦缉、突击/步枪训练。[全部职业数值与组合规则](docs/CAREERS.md)

旧职业、背景、技能树、灵魂与圣遗物继续保留。存档v6兼容v1—v5；职业ID仅追加，手动存档槽和应用ID不变。

## 0.6.0 · 1887灰桥封锁线 / 职业与历练

背景改为虚构的19世纪工业城镇：铁路、煤矿、纺织厂与墓园构成现实底色，光辉/禁忌灵魂和圣遗物保留为少数人接触的异常力量。营地可阅读事件档案；五段区域沿失踪夜班列车的线索推进。长外套、便帽、军刀与卡宾枪配合轨道、砖墙和煤气灯占位画面。[时代设定与当前边界](docs/SETTING.md)

- 三职业：护路卫士（生命/减伤）、边地猎人（机动）、秘仪学者（技能冷却）。各有两种专精，角色Lv.3开放，武器自由搭配。
- 六背景：铁厂学徒、乡间向导、铁路信使、乡村医护、墓园看守、码头拾荒者；分别影响入场护盾、补给、低血移动、药水、击杀恢复/魂能和敌人票券掉落。
- 六角色独立选择，营地免费调整、确认提交、取消保留；职业护盾和短时强化命中接入战斗HUD。
- 存档v5读取v1—v4，旧角色默认无职业/专精/额外经历。原武器、资源和存档ID保留，显示名称随时代变更。

[完整职业、专精与背景规则](docs/CAREERS.md)。枪械仍是简化投射物，无换弹；当前线索为文字展示，尚无分支剧情或交互调查任务。

## 0.5.0 · 圣遗物收藏

营地右上方打开「圣遗物」，共享收藏、六个角色独立双槽装备。初始拥有灯芯与罗盘；第2、4庭院及首领清场发现新遗物，失败仍保留，回营装备。集齐后节点改为本轮余烬+15。

- 八件遗物：生命灯芯、闪避罗盘、闪避后强化单次命中的铜铃、治疗与净化圣杯、初始魂能碎片、诅咒与献祭指环、受伤反震圣印、每轮一次的逆命沙漏。
- 光辉、禁忌及天赋效果可以组合；独立装备确认/取消、图鉴、战斗状态与发现提示已接入。
- v4存档兼容v1—v3，旧角色保持空装备槽；铜铃、沙漏消耗及发现节点记录随快照恢复。

[完整圣遗物规则与扩展指南](docs/RELICS.md)

## 0.4.0 · 光辉与禁忌灵魂

营地打开「灵魂祭坛」，为当前角色选灵魂与专属技能；也可在自定义角色工坊中编辑。战斗新增独立「魂技」按钮、魂能条、辉盾/侵蚀显示、领域与诅咒效果。

- **光辉**：圣钟震地、折光穿透箭、守誓环刃；专属「曙光圣域 / 裁决光矛」。强化治疗、防护与净化，主动技能冷却略长。
- **禁忌**：深渊牵引、咒棘箭雨、噬影环刃；专属「裂隙之井 / 血契狂宴」。更强的控制与爆发伴随生命献祭和侵蚀代价。
- 魂能通过有效命中积累，专属技能消耗40并独立计时。灵魂还强化灯芯/余温或三拍/借势天赋。
- 六个角色独立保存灵魂配置；v3快照兼容v1/v2，旧档保持未缔结。穿透命中记录、领域脉冲与全部临时状态一并恢复。

[完整灵魂规则与扩展指南](docs/SOULS.md)

## 0.3.0 · 角色工坊与天赋星图

- 三个独立自定义角色槽：名字、6种衣装色、3种肤色、3种发型；武器与主动技能分别选择。
- 3种出身、3种带代价的特质，与3武器×3技能组成81种战斗配置。
- 预设角色与自定义角色分别保存经验和天赋。初始2天赋点，随经验增长，最多16点。
- 三条分支共12节点，包含6个互斥终阶：连击震波、低血爆发、闪避脉冲、回避回能、技能治疗、护盾反震。营地免费重置。
- v2存档自动迁移v1：保留旧远征、角色经验与营地升级，按已有经验获得天赋点。

营地点「我的角色」→ 选槽 →「角色工坊」编辑；选中任意角色后点「技能树」培养。详见 [角色配置与天赋指南](docs/CHARACTER_BUILDS.md)。

## 这版可以玩什么

- 左摇杆自由移动，右侧按住攻击；多点触控支持移动、攻击、闪避和技能配合。
- 三种武器原型：军刀三连斩、自动瞄准卡宾枪、高速双匕首；各有独立技能。
- 实时近战命中、飞行弹丸、短暂无敌闪避、受击保护、硬直、命中停顿、伤害数字与短音效。
- 追击近战敌人、预警射手、直线冲锋敌人；第五房间为半血后加强弹幕的首领。
- 五段连续区域，每次重新生成障碍和敌群配置；清场选一项本轮增益，再走向恢复或资源出口。
- 局内伤害/生命/移速增益；角色经验与共享营地攻击/生命升级永久保留。
- 胜利带回所有票券并奖励 40；失败或主动结束带回已拾取票券的 70%。
- 自动快照 + 三个手动存档；保存敌人、弹丸、随机状态及冷却；切后台暂停，读档后先暂停。

**这是动作玩法模板，不是《莫塔守山人》的完整复刻。** 目前是五个单房间战斗关卡，随机化限于障碍和敌群；尚未提供完整随机地牢拓扑、剧情家庭系统、联机、装备词缀、正式美术与音乐、手柄或完整无障碍菜单。

## 下载和构建

在 GitHub 切换到 **demo** 分支，打开 **Actions → Action RPG checks and APK → 成功运行**，下载 `wayfarer-action-debug-apk` 中的 APK。`action-ui-smoke` 包含模拟器交互日志和截图。构建产物保留 14 天，可手动 Run workflow 重新生成。

本机需 JDK 17、Android SDK 35 和 Build Tools 35.0.0：

```bash
bash scripts/test-core.sh
bash gradlew lintDebug assembleDebug assembleDebugAndroidTest
```

Android Studio 打开项目后可直接 Run；Windows 构建用 `gradlew.bat`。APK 路径为 `app/build/outputs/apk/debug/app-debug.apk`。游戏支持 Android 8.0+，首次构建需联网下载工具，安装后离线运行。

测试版包名为 **`io.wayfarer.rpg.action`**，可与早先回合制 `io.wayfarer.rpg` 并存。两者玩法和存档格式不同，不会读取、覆盖或伪迁移旧版存档。旧回合制核心源码保留作历史兼容参考，已不接入应用入口。新建档案保留三个手动槽。

Debug APK 只用于测试。不同 CI 构建机可能使用不同 debug 签名，长期发布需要自己的固定签名；密钥不可提交。正式发布时递增 versionCode。

## 手机操作

| 操作 | 行为 |
|---|---|
| 左摇杆 | 连续移动，可同时攻击 |
| 按住攻击 | 连续攻击；优先瞄准视线内最近敌人 |
| 闪避 | 沿移动方向闪避；静止时沿朝向，冷却 1.15 秒 |
| 技能 | 震地、扇形散射、环刃；冷却 7 秒 |
| 药水 | 每轮 2 瓶，基础恢复 45% 生命；圣杯可在满血时净化禁忌侵蚀 |
| 暂停 | 停止敌人、弹丸和冷却，可存档、调音效、结束本轮 |
| 房间出口 | 清场并选择奖励后，向上走；左门恢复，右门额外资源 |

敌人的红圈/直线是攻击预警。首领重击范围较大，需要提前离开；闪避不能持续连按。回营地后可换角色，各角色经验独立，共享升级对所有角色生效。

## 源码结构

| 模块 | 文件 | 职责 |
|---|---|---|
| 职业与背景 | `core/CareerSystem.java` / `CareerHall.java` | 独立职业、等级门槛、专精和背景被动 |
| 时代设定 | `core/WorldSetting.java` | 1887灰桥档案、地点和环境线索 |
| 圣遗物 | `core/RelicSystem.java` / `RelicCabinet.java` | 稳定ID、双槽校验、图鉴与装备草稿 |
| 灵魂定义 | `core/SoulSystem.java` | 灵魂ID、变体、专属技能和共鸣数据 |
| 灵魂祭坛 | `SoulAltar.java` | 草稿选择、效果与代价说明、确认缔结 |
| 角色与天赋 | `core/BuildSystem.java` | 独立档案、数据定义、预算与前置校验 |
| 原生编辑器 | `CharacterWorkshop.java` | 草稿编辑、外观预览、确认提交 |
| 即时规则 | `core/ActionGame.java` | 固定步长战斗、碰撞、AI、房间与成长 |
| 快照协议 | `core/ActionSave.java` | 版本化、有界存档编码与校验 |
| 显示/输入 | `WorldView.java` | 原生 Canvas、相机、触控与帧循环 |
| 生命周期 | `MainActivity.java` | 后台暂停、读写存档、菜单确认 |
| 磁盘存储 | `SaveStore.java` | 私有目录与 AtomicFile 写入 |
| 音效 | `GameAudio.java` | SoundPool 与原创短音效 |
| 核心测试 | `tests/ActionTests.java` | 战斗、布局、进度和快照回归 |
| Android 验证 | `SmokeInstrumentation.java` | 实际 Activity、多指操作、暂停及快照验证 |

应用 Java 文件位于 `app/src/main/java/io/wayfarer/rpg/`。测试 runner 位于 `app/src/androidTest/java/io/wayfarer/rpg/`。
