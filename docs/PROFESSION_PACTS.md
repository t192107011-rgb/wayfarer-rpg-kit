# 职业性格与可选禁术 · 0.7.0

8种日常职业各有不同的行事倾向、发动台词和一项职业禁术。行事倾向用于扮演提示，不强制角色的道德立场，也不覆盖原有可选性格特质。性格呈现在职业面板与禁术发动时的短句，目前是文字，没有配音、NPC关系或分支剧情。

## 人物区别

| 职业 | 行事倾向 | 越过界线时的诱惑 |
|---|---|---|
| 警员 | 谨慎、重秩序，观察局势与破绽 | 把维持秩序变成绝对控制 |
| 退役军人 | 寡言、自律，相信训练和同伴 | 为避免再次失去同伴而拒绝撤退 |
| 医生 | 细心、有同情心，总想保住救人的余地 | 为眼前生命透支之后的恢复能力 |
| 机械师 | 务实、讲究细节，相信工具与维修 | 强迫装备突破安全极限 |
| 矿工 | 坚韧、重互助，先寻找支撑和出口 | 借地下异物强行开路 |
| 拳击手 | 直率、好胜，擅长近身节奏 | 把不肯服输变成透支身体 |
| 商人 | 精于权衡、重信用，习惯保留余地 | 在绝境押上本钱 |
| 记者 | 好奇、执拗，记住细节并追问 | 为揭露真相主动暴露自己 |

## 玩家明确选择

营地「职业与历练」的右侧勾选框默认关闭。角色Lv.3后可阅读收益和代价，勾选并确认才开启。取消不提交；切换职业会清空禁术草稿，避免自动接受另一种代价。原有三个职业暂未追加职业禁术，仍可选择灵魂祭坛中的能力。

开启后战斗增加独立「禁术」按钮，位置在药水上方、魂技左侧。职业禁术不要求缔结灵魂，可以与光辉或禁忌灵魂并用，也不替换原有魂技。不开启仍能使用普通职业的全部基础被动和专精。

| 记者 · 禁闻揭露 | 打断400范围普通敌人的攻击并硬直0.8秒；首领仅硬直0.15秒；有效攻击伤害+60% | 支付12%最大生命，期间受伤+35% | 6秒 / 28秒 |

生命支付必须付得起并存活，否则整次施放拒绝，不扣资源、不进入冷却。票券不足、满血医生、枪械拳击手、非战斗状态、闪避中、清场后和冷却中均不能施放。职业生命支付不经过敌方伤害减免、不触发受伤反击，也不享受渎誓指环的灵魂献祭折扣；它不会暗中增加灵魂侵蚀。

## 与既有系统的边界

- 有效攻击包括普攻、主动技能和攻击型天赋，不包括魂技、领域、镜火/荆棘反震。矿工禁术本身不充能、不吸血、不消耗铜铃或职业强化。
- 医生的首次恢复先计算既有治疗系数，再进入治疗封锁。因此侵蚀会削弱首次恢复，药物护理和圣杯可以增强；封锁后药水、技能治疗、吸血、地面恢复和领域治疗都归零。受阻药水不消耗瓶数。
- 超载期间主动技能的生命支付与禁忌灵魂自身献祭分别计算；无力支付额外4%时，主动技能不发动。过载只重置主动技能，不重置灵魂技能或职业禁术自身冷却。
- 矿工临时护盾与入场职能护盾分别保存，吸收顺序：辉盾→禁术临时护盾→职能护盾→天赋护盾；持续结束后未用完的禁术护盾消失。光辉吸收回能与镜火仍可响应防护，反应伤害不获得禁术增伤。
- 增益与负面状态共用真实剩余持续时间，战斗HUD同时显示收益与当前代价。暂停、奖励界面、后台冻结时间；进入下一区域不会消除负面状态、刷新禁术冷却或补足临时护盾。结束本轮回营才清空运行状态，保留选择。
- 伤害与易伤可和天赋、灵魂、圣遗物相乘；强力效果也会放大原有风险，数值仍为动作模板的初始平衡。

## 快照与实现

协议v7读取v1—v7。六个角色分别保存`careerPacts`选择，运行状态为`pactCd`、`pactTime`、`pactWard`。旧档默认关闭职业禁术，保留职业、专精、背景、灵魂与遗物。读档只恢复剩余量，不重复收取生命/票券，也不重新治疗或补盾；校验职业、等级、武器条件、持续/冷却上限和护盾来源。

`ProfessionPacts.java`统一保存行事文案、台词、名称、代价与时限，`ActionGame`执行效果，`CareerHall`只编辑草稿，`WorldView`展示独立按键、状态与短句。自动测试覆盖144组禁术/武器/灵魂/专精组合，原普通职业和旧系统测试继续保留。
