## 连招与敌人

初段主动技能后2秒内再按同一按键发动一次追击，初段冷却继续计算；错过窗口不能补发。武器和主动技能仍可分别选择。

| 追击 | 用途 |
|---|---|
| 断层追击 | 前方260距离直线；1.3倍伤害，眩晕目标1.95倍，适合初段震地后衔接 |
| 破盾点射 | 前方540距离窄线；移除敌方护盾，1.8倍伤害，墙体阻挡 |
| 穿影突刺 | 最多位移145，碰墙停下；1.5倍伤害，对蓄力目标2.1倍，附0.18秒短暂无敌 |

光辉追击命中补8辉盾（总上限30），并净化自身110范围弹丸。禁忌追击支付2%最大生命、增加12侵蚀；命中已诅咒目标会消耗诅咒，对周围其他敌人造成0.65倍次生伤害，遵守视线、不递归充能。机械师职业禁术生效时追击还需额外支付4%生命，付不起则不发动。

| 敌人 | 压力与应对 |

| 失魂工人 | 贴近挥击，攻击伤害与接近速度提高；留意短预警 |
| 封锁枪手 | 后撤、双轮三发扇射；第一轮后不要立刻回到原线路 |
| 冲撞搬运工 | 长距离冲锋，固定方向；侧移后利用恢复期 |

| 焚灯者 | 两个延迟火区封路；预警期间离开，别踩回仍燃烧区域 |

所有新危险区先预警再伤害，并受障碍视线限制。房间清场移除危险区，避免奖励界面后遭到残留攻击。数值仍是第一轮调校，精通走位、控制和成长构筑依然可以减少伤害。

## 侵蚀

初段+18、追击+12、魂技+30。禁忌技能后8秒才开始每秒下降1点，活跃血契/领域暂停下降，因此约6.4秒一轮的连续技能可持续积累。承伤和减疗旧效果保留。

50侵蚀输出+15%，75侵蚀输出+25%；100进入6秒失控，输出+40%，每1.5秒失去3%最大生命，献祭不致死。失控不会在100反复刷新，需结束并降至70以下才解除阈值锁。暂停/选奖励冻结计时，跨房间侵蚀与失控保留，回营/新远征重置。圣杯、停止施法和退出本轮仍可控制侵蚀。

## 主线与人物

1887年灰桥，站务员诺拉寻找失踪弟弟阿伦。五章依次为「没有乘客的列车」「岔道里的口令」「仍在上工的人」「提前写好的死亡」「黑钟之下」。清场后点击现场线索，不强制打断奖励流程；已解锁内容可在营地手记补读。

每章二选一，永久记录，不随重新远征重发：救援路线获得12营地票券，取证路线给当前角色20经验。五章全部选择后，最后选择救援且至少三次救援为「归途有名」；最后选择取证且最多两次救援为「墨迹未干」；其他组合为「灯下余声」。当前结局为文字变化，不生成新地图。

人物线由当前角色清场解锁：任意首次清场解锁旧事，三区及之后解锁裂痕，五区解锁回声。六个角色各自保存三个决定；首次清场锁定人物故事的职业起点，换职业不改写过去。11职业加无职业共12套三段文本，日常职业各自围绕职责、性格与过去展开。只能回营决定：守护每章+4生命上限，决意每章+1基础伤害。两种决定都不启用职业禁术。

新剧情为原创文字与选择，没有配音、可行走NPC或动画过场。八种出格职业禁术仍独立、可选，与主线救援/取证不存在自动捆绑。
