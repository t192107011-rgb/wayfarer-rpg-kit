# 四种职业 · 0.9.1

当前职业系统已整体重做，只存在四个职业，ID连续且从0开始。所有六个角色档案分别保存职业、专精和背景。旧版本职业编号不再兼容；读取v1—v10存档时，职业统一重置为猎人，专精重置为无专精，背景经历保留。角色武器、出身、特质、经验、天赋、灵魂、圣遗物、剧情和战斗进度继续保留。

## 职业与主动技能

| 职业 | 主动技能 | 实际效果 |
|---|---|---|
| 猎人 | 火力强化 | 持续5秒。子弹命中产生小范围溅射；近战攻击范围增加35%。 |
| 刺客 | 狂袭 | 持续5秒。受到伤害降低80%，获得相当于最大生命值40%的护盾，普攻伤害提高50%，移动速度提高25%。 |
| 侦探 | 引力场 | 持续3.5秒。大范围持续吸附敌人并造成低额伤害；敌人死亡时触发一次中范围追击，触发间隔至少2秒。 |
| 记者 | 群体曝光 | 发动大范围伤害并持续5秒。期间有效攻击会使其他敌人分担原攻击实际伤害的70%；场上只剩一个敌人时，攻击伤害提高至200%。 |

职业主动技能由战斗中的「技能」按键触发；魂技由独立的「魂技」按键触发。职业技能不依赖灵魂绑定。四种职业的主动技能不能互换，也不会因武器类型变化。

### 具体触发规则

- 猎人：溅射只由友方子弹命中触发；每次命中产生一次小范围伤害，不会无限递归溅射。近战范围增幅只在猎人主动技能持续时间内生效。
- 刺客：40%最大生命护盾按发动时最大生命值计算；80%减伤作用于敌方伤害，不减免自我支付。攻击与移速增幅在技能计时结束时一并结束。
- 侦探：引力场持续更新位置，吸附受障碍空间限制；伤害较低，控制与位置改变是主要效果。死亡追击由敌人实际死亡事件触发，2秒内最多触发一次。
- 记者：初次发动先对范围内敌人造成伤害；持续期间的有效攻击再执行伤害分担。分担只传播一层，不会继续递归传播。单个敌人时改为原攻击伤害的200%。

## 专精

角色达到Lv.3（160经验）后开放专精。猎人与记者各有两个专精；刺客和侦探目前没有专精。

| 职业 | 专精 | 效果 |
|---|---|---|
| 猎人 | 狙猎 | 距离目标超过200时，有效攻击伤害提高18%。 |
| 猎人 | 游击 | 闪避后3秒内，下一次有效攻击伤害提高25%。 |
| 记者 | 战地采访 | 对首领的有效攻击伤害提高15%。 |
| 记者 | 调查报道 | 本轮结算角色经验提高20%，向下取整。 |

专精只影响对应职业。切换职业时专精归零；切换角色不会共享专精。职业技能、专精与背景可以自由组合，不限制武器、出身、特质、灵魂或圣遗物。

## 背景经历

背景与职业独立，可自由组合；六个背景的实际效果保留：

| 背景 | 效果 |
|---|---|
| 无额外经历 | 不附加背景被动。 |
| 铁厂学徒 | 每次进入新区域获得10点职能护盾。 |
| 乡间向导 | 移速额外提高3%；补给所基础恢复由18%提高到26%最大生命。 |
| 铁路信使 | 生命低于35%时，移动速度额外提高12%。 |
| 乡村医护 | 每瓶药水基础恢复额外增加6生命。 |
| 墓园看守 | 击败敌人基础恢复1生命；已缔结灵魂时获得魂能，普通敌人2点、首领8点。 |
| 码头拾荒者 | 每名敌人的票券掉落额外增加2。 |

背景、出身与性格特质分别生效。更换职业不会删除背景。

## 已移除内容

旧职业：护路卫士、边地猎人（旧ID）、秘仪学者、警员、退役军人、医生、机械师、矿工、拳击手、商人，以及旧职业禁术系统，均已从当前职业系统删除。旧专精与旧职业被动不再生效。时针没有加入本次职业列表。

## 存档与实现

- 当前快照协议为v11。
- v1—v10旧存档读取时，所有角色职业重置为猎人，专精重置为无专精；原背景经历保留。
- v11开始使用紧凑职业ID：猎人0、刺客1、侦探2、记者3。
- CareerSystem.java 定义职业、专精、背景与校验；ActionGame.java 执行主动技能和实际效果；CareerHall.java 提供营地选择界面；ActionSave.java 负责v11快照和旧档迁移。
- 职业测试覆盖四种主动技能、专精门槛、职业选择、存档恢复与旧档迁移。
